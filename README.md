# Analyse des propriétaires de supports

Ce script Python étudie la répartition des propriétaires de supports radioélectriques à partir des données de l'ANFR.

## Fonctionnalités

- Lecture des fichiers `sup_support.txt` et `sup_proprietaire.txt` avec Pandas.
- Comptage des supports par propriétaire.
- Affichage des résultats et d'un graphique des 5 propriétaires les plus représentés avec Matplotlib.

## Données utilisées

Les fichiers sont lus depuis les répertoires `data/data` et `ref/ref` de mon dossier SAE15, grâce aux chemins définis dans le script.
